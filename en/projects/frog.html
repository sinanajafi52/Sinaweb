What it’s about

Frog controls a peristaltic pump. In Status mode it runs continuously at an adjustable speed (0–300 rpm) and direction; in Dispenser mode it doses by alternating run and pause times. Everything is operated via a rotary encoder and a small display.

04

Problems I solved

CASE 1

STOP responded with a delay

CAUSE

The motor control used HAL_Delay and blocked the main loop for around 600 ms.

SOLUTION

Rewritten to be non-blocking: step pulses are timed via HAL_GetTick, and the button is read in every pass of the loop.

CASE 2

Motor driver failed

CAUSE

The current limit of the DRV8825 had not been set.

SOLUTION

VREF is now set before every commissioning (VREF = I × 0.5).

CASE 3

Porting ESP32 → STM32

CAUSE

Arduino libraries and C++ code could not be carried over.

SOLUTION

Rebuilt in C with HAL: pins configured in CubeMX, logic split into modules, each feature developed on its own branch.
