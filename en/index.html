FROG · PERISTALTIC PUMP · SINCE 12/2025

Pump control – from an ESP32 prototype to modular STM32 firmware

Frog controls a peristaltic pump with adjustable speed, direction of rotation and timed dosing. I designed the housing myself in Fusion 360 and SolidWorks and printed it using FDM.

v1 · 12/2025
ESP32 · C++
DRV8825 with 1/32 microstepping, TFT display via SPI, storage in flash, watchdog, non-blocking state machines. IoT: captive portal, Firebase and the PWA dashboard “SinoLab”.
v2 · current
STM32F103 · C
Modular rebuild in C with HAL: rotary encoder via interrupt, menu built from nested state machines (Status / Dispenser), developed with feature branches and pull requests.
